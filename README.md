# GEO Engine Backend

Free testing version of RankAI-style GEO (Generative Engine Optimization) backend.

## Free Stack
- **Content Generation**: Google Gemini (`gemini-1.5-flash`)
- **Crawling**: Simple Cheerio crawler

## Setup

```bash
npm install
cp .env.example .env
# Add your GEMINI_API_KEY
npm run test:free
```

## Get Gemini API Key (Free)
https://aistudio.google.com/app/apikey
